重要的三个部分

场景、相机、渲染器

```plain
// 创建3D场景对象Scene
const scene = new THREE.Scene();

// 实例化一个透视投影相机对象
const camera = new THREE.PerspectiveCamera();

// 创建渲染器对象
const renderer = new THREE.WebGLRenderer();

```

总结来说就是<font style="background-color:#FBDE28;">创建一个可供观测的场景</font>，在场景中放入可以观测到的模型。<font style="background-color:#FBDE28;">通过相机进行观测</font>（相机类似于眼睛），<font style="background-color:#FBDE28;">最后将场景和相机进行渲染</font>，使之展示在网页中。

场景中可以放入各种<font style="background-color:#FBDE28;">模型</font>（网格模型、外部导入的模型），模型由<font style="background-color:#FBDE28;">几何体</font>和<font style="background-color:#FBDE28;">材质</font>组成

几何体

```plain
//创建一个长方体几何对象Geometry
const geometry = new THREE.BoxGeometry(100, 100, 100); 

```

材质

```plain
//创建一个材质对象Material
const material = new THREE.MeshBasicMaterial({
    color: 0xff0000,//0xff0000设置材质颜色为红色
}); 

```

模型

```plain
// 两个参数分别为几何体geometry、材质material
const mesh = new THREE.Mesh(geometry, material); //网格模型对象Mesh
//设置网格模型在三维空间中的位置坐标，默认是坐标原点
mesh.position.set(0,10,0);
```

模型创建好了我们需要把他加入到场景中去

```plain
scene.add(mesh); 

```

接下来就是用相机观测了

创建相机

```plain
// 实例化一个透视投影相机对象
const camera = new THREE.PerspectiveCamera();


```

相机的位置，相机在哪里进行观测

```plain
//相机在Three.js三维坐标系中的位置
// 根据需要设置相机位置具体值
camera.position.set(200, 200, 200); 

```

看向哪里，默认看向坐标原点

```plain
//相机观察目标指向Threejs 3D空间中某个位置
camera.lookAt(0, 0, 0); //坐标原点
camera.lookAt(0, 10, 0);  //y轴上位置10
camera.lookAt(mesh.position);//指向mesh对应的位置，重心的位置坐标

```

看多大范围，定义相机渲染输出的画面尺寸

```plain
// width和height用来设置Three.js输出的Canvas画布尺寸(像素px)
const width = 800; //宽度
const height = 500; //高度
// 30:视场角度, width / height:Canvas画布宽高比, 1:近裁截面, 3000：远裁截面
const camera = new THREE.PerspectiveCamera(30, width / height, 1, 3000);

```

创建渲染器

```plain
// 创建渲染器对象
const renderer = new THREE.WebGLRenderer();

```

设置渲染的范围大小

```plain
// 定义threejs输出画布的尺寸(单位:像素px)
const width = 800; //宽度
const height = 500; //高度
renderer.setSize(width, height); //设置three.js渲染区域的尺寸(像素px)

```

执行渲染操作

```plain
renderer.render(scene, camera); //执行渲染操作

```

将渲染的画面加入html元素上

```plain
document.body.appendChild(renderer.domElement);


<div id="webgl" style="margin-top: 200px;margin-left: 100px;"></div>
document.getElementById('webgl').appendChild(renderer.domElement);

```

这样就可以输出一个可供观测的3D模型。
